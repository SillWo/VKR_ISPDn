# Frontend

Минимальный React + Vite + TypeScript интерфейс платформы учёта и контроля ИСПДн.

## Установка и запуск

```powershell
cd frontend
npm install
npm run dev
```

## Production build

```powershell
npm run build
```

## Переменные окружения

Для подключения к backend используется:

```env
VITE_API_BASE_URL=http://localhost:8000
```
